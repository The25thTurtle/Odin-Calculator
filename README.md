# JavaScript Calculator

## Overview

The JavaScript Calculator is a browser-based calculator built to perform basic mathematical operations. The project focuses on JavaScript fundamentals, including functions, variables, event handling, and DOM manipulation.

Users can perform calculations using an interactive calculator interface with support for chained operations and input validation.

## Features

- **Basic Arithmetic:** Addition, subtraction, multiplication, and division.
- **Interactive Interface:** Buttons for numbers, operators, equals, and clear.
- **Chained Calculations:** Perform multiple operations sequentially without restarting.
- **Decimal Handling:** Rounds long decimal results to prevent display overflow.
- **Division by Zero Protection:** Displays an error message when attempting to divide by zero.
- **Clear Function:** Resets the calculator and clears stored values.
- **Input Validation:** Prevents incomplete calculations and consecutive operators from triggering unintended operations.
- **Result Handling:** Starting a new calculation after receiving a result clears the previous result automatically.

## Getting Started

### Prerequisites

- A modern web browser.
- A code editor (Visual Studio Code recommended).

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder.

3. Open `index.html` in your browser.

No additional dependencies or installations are required.
